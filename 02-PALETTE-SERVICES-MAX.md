## 🔧 Pipelines de production maîtrisés (ce qui rend tout ça livrable en solo)
1. **Pipeline vidéo immo (PROD'AI)** — 14 étapes : données bien → WHO/WHY/JTBD/PAIN → angle émotionnel → 5 hooks → VO premium + version conversion → sous-titres timecodés → brief visuel → montage → design sonore → CTA verbal+écran → caption → Stories → automatisation DM.
2. **Pipeline séries / cartoons** — distillation → passeport canonique → scénario 9:16 → prompts image → prompts vidéo → montage → diffusion.
3. **Pipeline avatar** — identity lock → passeport comportemental → voix (test sur vrai script, ID conservé) → candidats HeyGen → QA (lip-sync, réalisme) → Live Avatar.
4. **Pipeline business 19 étapes** — concept → deck Canva + Notion + Miro.
5. **Système d'organisation** — conventions de nommage, master sets réutilisables, un MASTER officiel + changelog + archives, negative prompts, bibliothèque de prompts validés.

## 🧱 Briques standard réutilisables (les « lego » du studio)
CRM · Telegram · Drive/OCR · reporting · relance · base de connaissances · coquille avatar · master sets · bibliothèque de prompts · ID de voix · identity lock + negative prompts.
